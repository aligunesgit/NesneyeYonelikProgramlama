# 🔗 M4 - Nesneler Arası İlişkiler ve UML

<p align="center"><em>Hafta 4</em></p>

UML sınıf diyagramı; ilişkilendirme, toplama, bileşim ve bağımlılık.

!!! info "Durum"

    Bu modülün içeriği hazırlanıyor. Aşağıdaki başlıklar planlanan kapsamı gösterir.

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* UML sınıf diyagramını okumak ve çizmek
* İlişkilendirme, toplama, bileşim ve bağımlılığı ayırt etmek
* Bir diyagramı Java koduna, Java kodunu diyagrama dönüştürmek

## 📚 İçerik

1. UML sınıf diyagramı
2. İlişkilendirme (association) ve çokluk
3. Toplama (aggregation)
4. Bileşim (composition)
5. Bağımlılık (dependency)
6. Diyagramdan koda, koddan diyagrama

## 🧪 Alıştırmalar

Bu modülün alıştırmaları `exercise_files/` klasöründeki Maven projesindedir: kaynak kod
`src/main/java/nyp/m4/`, testler `src/test/java/` altında.

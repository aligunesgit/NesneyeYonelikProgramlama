# 📐 M11 - Tasarım İlkeleri

<p align="center"><em>Hafta 12</em></p>

SOLID ilkeleri, kalıtım yerine bileşim, test edilebilir tasarım.

!!! info "Durum"

    Bu modülün içeriği hazırlanıyor. Aşağıdaki başlıklar planlanan kapsamı gösterir.

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* SOLID ilkelerini örneklerle açıklamak
* Bir tasarımdaki ilke ihlallerini bulup yeniden düzenlemek
* Bağımlılıkları arayüzlerle gevşetip test edilebilir kod yazmak

## 📚 İçerik

1. İyi tasarım neden önemli?
2. Tek sorumluluk (SRP)
3. Açık/kapalı (OCP)
4. Liskov yerine geçme (LSP)
5. Arayüz ayrımı (ISP)
6. Bağımlılığın tersine çevrilmesi (DIP)
7. Kalıtım yerine bileşim

## 🧪 Alıştırmalar

`src/main/java/nyp/m11/`, testler `src/test/java/` altında.

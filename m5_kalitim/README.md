# 🧬 M5 - Kalıtım

<p align="center"><em>Hafta 5</em></p>

extends, super, metot ezme, protected, Object sınıfı: toString, equals, hashCode.

!!! info "Durum"

    Bu modülün içeriği hazırlanıyor. Aşağıdaki başlıklar planlanan kapsamı gösterir.

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* Bir üst sınıftan alt sınıf türetmek
* super ile üst sınıfın kurucusunu ve metotlarını çağırmak
* toString, equals ve hashCode metotlarını doğru ezmek
* Kalıtımın ne zaman uygun olmadığını fark etmek

## 📚 İçerik

1. Kalıtım ve "bir tür" (is-a) ilişkisi
2. extends ve super
3. Metot ezme (override) ve @Override
4. protected erişim
5. Object sınıfı: toString, equals, hashCode
6. Kalıtımın sınırları

# 🚨 M8 - İstisna Yönetimi

<p align="center"><em>Hafta 9</em></p>

try/catch/finally, checked ve unchecked istisnalar, kendi istisna sınıfları, try-with-resources.

!!! info "Durum"

    Bu modülün içeriği hazırlanıyor. Aşağıdaki başlıklar planlanan kapsamı gösterir.

## ❔ Öğrenme hedefleri

Bu modülün sonunda öğrenci:

* Hata durumlarını istisnalarla bildirmek ve yakalamak
* Checked ve unchecked istisnaları ayırt etmek
* Alan kurallarına özgü istisna sınıfları yazmak
* İstisna fırlatan kodu JUnit ile test etmek

## 📚 İçerik

1. Hata yönetimi neden gerekli?
2. try, catch, finally
3. İstisna hiyerarşisi: checked ve unchecked
4. throw ve throws
5. Kendi istisna sınıflarımız
6. try-with-resources
7. assertThrows ile test

## 🧪 Alıştırmalar
